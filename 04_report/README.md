# Research report

[Read the report](health_discourse_report.pdf)

This report extends an earlier group project on Italian parliamentary
health discourse through semantic comparisons across five source party
categories before and during COVID-19.

It presents the data, methods, results, robustness checks and limitations
of the analysis documented in this repository.

## Files

- `health_discourse_report.pdf`: compiled report.
- `main.tex`: LaTeX source.
- `semantic_party_dendrograms.pdf`: hierarchical clustering figure.
- `semantic_distance_changes.pdf`: distance changes and bootstrap intervals.

Compile `main.tex` with the two figure files in the same directory.
